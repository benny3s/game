# 고스톱 규칙 (이 게임에서 쓰는 한 가지)

한 판은 **맞고(2인) 아니면 3인 고스톱**이에요. 4~5명이 모이면 3명이 치는 3인 고스톱에 **광 팔기**가 붙어요 (아래 "인원 · 광 팔기"). 친구랑 방은 인원을 미리 안 정하고, 시작할 때 모인 사람 수로 정해져요.

지역·집마다 규칙이 많이 달라서, 이 문서의 기본은 아래 한 가지로 정했고 **하나하나 바꿀 수 있어요** (맨 아래 "🛠️ 우리 집 규칙"). 아래에 적힌 숫자는 모두 **기본값**이에요. 규칙은 `core.js` 가 그대로 따르고, `test/selftest.js` 가 하나하나 확인해요. 게임 안 📖 규칙 창은 **지금 쓰는 우리 집 규칙**을 그대로 보여 줘요. 점수는 놀이용 **점**과 🪙 **냥코인**(이긴 점 × 10)으로만 쌓여요. 친구랑에서는 점수 × **점당 칩**(기본 10칩)으로 정산용 칩이 오가요 (실제 돈은 앱 밖에서).

## 패

- 화투 48장 = 열두 달 × 네 장. 같은 달끼리 짝이 맞아요.
- 종류: **광** 5장 · **열끗** 9장 · **띠** 10장 · **피** 24장 (쌍피 2장 포함).

| 달 | 이름 | 네 장 |
|---|---|---|
| 1월 | 송학 | 광(학) · 홍단 · 피 · 피 |
| 2월 | 매조 | 열끗(꾀꼬리, 고도리) · 홍단 · 피 · 피 |
| 3월 | 벚꽃 | 광(장막) · 홍단 · 피 · 피 |
| 4월 | 흑싸리 | 열끗(두견새, 고도리) · 초단 · 피 · 피 |
| 5월 | 난초 | 열끗(다리) · 초단 · 피 · 피 |
| 6월 | 모란 | 열끗(나비) · 청단 · 피 · 피 |
| 7월 | 홍싸리 | 열끗(멧돼지) · 초단 · 피 · 피 |
| 8월 | 공산 | 광(보름달) · 열끗(기러기, 고도리) · 피 · 피 |
| 9월 | 국화 | 열끗(술잔 = 국진) · 청단 · 피 · 피 |
| 10월 | 단풍 | 열끗(사슴) · 청단 · 피 · 피 |
| 11월 | 오동 | 광(봉황) · 쌍피 · 피 · 피 |
| 12월 | 비 | 광(비광) · 열끗(제비) · 띠(단 없음) · 쌍피 |

- **보너스 피** (설정): 없음 · 2장(쌍피 + 쓰리피) · 3장(쌍피 두 장 + 쓰리피). 쌍피는 피 2장, 쓰리피는 피 3장으로 셈.

## 인원 · 광 팔기

| 모인 사람 | 방식 | 한 판에 |
|---|---|---|
| 2명 | 맞고 | 둘이 침 |
| 3명 | 고스톱 | 셋이 침 |
| 4명 | 광 팔기 고스톱 | 3명이 치고 **1명이 쉼** |
| 5명 | 광 팔기 고스톱 | 3명이 치고 **2명이 쉼** |

- **쉬는 사람 돌리기**: 자리 순서(0번부터)를 판마다 (모인 수 − 3)칸씩 돌려서 앞 3명이 쳐요. 4명이면 한 명씩 차례로, 5명이면 두 명씩 차례로 쉬어요. 4명은 4판, 5명은 5판이 돌면 모두 같은 횟수(4명: 1번, 5명: 2번)씩 쉬어요.
- **선**: 이긴 사람 (나가리면 그대로). 다음 판에 쉬게 된 사람이면 새로 치는 사람 중 맨 앞이 선이에요.
- 점수 계산은 셋이 치는 고스톱과 똑같아요 (3점부터 고/스톱, 피박 5장 이하 …).

**광 팔기** (이 게임의 방식)
1. 패를 나눈 뒤, 쉬는 사람이 더미 위에서 **7장씩** 받아 둬요. 이 패는 아무에게도 안 보여요.
2. 쉬는 사람 패에 **광**이 있으면 그 광만 판에 내놓아요 (한 사람이 낸 광은 한 묶음). 광이 없으면 바로 시작해요.
3. 치는 사람이 **선부터 차례로** 그 묶음을 살지 답해요. 처음으로 "산다"한 사람이 묶음 전부를 가져가 자기 **먹은 패**로 삼아요 (광 점수·광박에 셈). 셋 다 안 사면 안 팔려요.
4. 쉬는 사람이 둘(5명)이면 묶음이 둘까지 나올 수 있고, 묶음마다 다시 선부터 물어요.
5. **값**: 광 **한 장에 1점**, 산 사람이 판 사람(쉬는 사람)에게 줘요. 그 판을 이기든 지든 똑같고, 나가리여도 내요. 총통이면 광 팔기를 건너뛰어요.
6. 안 팔린 패와 쉬는 사람의 나머지 패는 섞어서 **더미 맨 아래**로 돌아가요 (본판 더미는 보통과 같은 장수).

## 나누기

- **맞고(둘이)**: 한 사람 10장, 바닥 8장, 나머지는 더미.
- **고스톱(셋이)**: 한 사람 7장, 바닥 6장, 나머지는 더미.
- 바닥에 깔린 보너스 피는 선이 가져가고, 그 자리는 더미에서 채워요.
- 바닥에 같은 달 네 장이 깔리면 다시 섞어요. 같은 달 세 장이 깔리면 주인 없는 더미가 돼요 (네 번째로 먹어도 피는 안 받음).
- 첫 판은 내가 선, 그다음부터는 이긴 사람이 선 (나가리면 그대로).

## 내 차례

1. 손패 한 장을 내요. 바닥에 같은 달이 있으면 그 위에, 없으면 그냥 바닥에.
   - 바닥에 같은 달이 두 장이고 둘이 다르면(예: 광과 피) 하나를 골라요. 똑같은 보통 피 두 장이면 묻지 않아요.
   - 바닥에 같은 달이 세 장(뻑 더미)이면 네 장을 다 가져와요.
2. 더미에서 한 장을 뒤집어 똑같이 해요 (고르기도 똑같이).
3. 짝이 맞은 패를 가져와요.

## 특별한 일

| 이름 | 언제 | 결과 |
|---|---|---|
| 쪽 | 짝 없이 낸 패를 뒤집은 패가 바로 맞힘 | 두 장 + 상대마다 피 1장 |
| 뻑 | 낸 패로 한 장과 짝을 맞췄는데, 뒤집은 패도 같은 달 | 세 장이 바닥에 남음 (아무것도 못 가져옴) |
| 뻑 먹기 | 남이 싼 뻑 더미를 네 번째 패로 먹음 | 네 장 + 피 1장씩 |
| 자뻑 먹기 | 내가 싼 뻑 더미를 내가 먹음 | 네 장 + 피 **2장**씩 |
| 따닥 | 바닥 같은 달 두 장에 내고, 뒤집은 패가 네 번째 | 네 장 + 피 1장씩 |
| 싹쓸이 | 내 차례가 끝났을 때 바닥이 텅 빔 (뭔가 먹었을 때) | 피 1장씩 (따닥·쪽과 겹치면 둘 다) |
| 폭탄 | 손에 같은 달 세 장 + 바닥에 그 달 한 장 | 세 장을 한꺼번에 내 네 장 다 + 피 1장씩 · 흔들기로 셈(×2) · 그 뒤 '뒤집기만' 2번 |
| 흔들기 | 손에 같은 달 세 장(바닥엔 없음) | 그중 한 장을 낼 때 세 장을 보여 주면, 이겼을 때 ×2 (같은 달은 한 번) |
| 보너스 피 | 손에서 냄 / 더미에서 나옴 | 손: 바로 내 피 + 더미에서 한 장 받아 계속 · 더미: 바로 내 피 + 한 장 더 뒤집음 |
| 총통 | 처음 받은 손패에 같은 달 네 장 | 바로 이김, 10점 |
| 쓰리뻑 | 한 판에 뻑을 세 번 | 바로 이김, 맞고 7점 · 셋이 3점 |

- 피를 받을 때는 상대의 **가장 값이 낮은 피**부터 (보통 피 → 쌍피 → 쓰리피). 피가 없는 사람에겐 못 받아요.
- **마지막 차례**(모든 사람이 손패를 다 낸 차례)의 쪽·따닥·싹쓸이·뻑 먹기는 피를 안 받아요.
- '뒤집기만'(폭탄 뒤): 손패를 내지 않고 더미만 뒤집어요. 폭탄으로 줄어든 손패 수를 맞추는 것이라 차례 수는 모두 같아요.

## 점수

| 종류 | 점수 |
|---|---|
| 광 | 3장 3점 (비광이 끼면 2점) · 4장 4점 · 5장 15점 |
| 열끗 | 5장 1점, 한 장마다 +1 |
| 고도리 | 2·4·8월 새 세 장 5점 |
| 띠 | 5장 1점, 한 장마다 +1 (12월 띠도 띠) |
| 홍단 · 청단 · 초단 | 각 3점 (1·2·3월 · 6·9·10월 · 4·5·7월) |
| 피 | 피 10장 1점, 한 장마다 +1 (쌍피 2장, 쓰리피 3장) |

- **국진**(9월 술잔): 먹는 그 자리에서 **열끗**으로 둘지 **쌍피**로 쓸지 골라요. 고른 대로 끝까지 가요. 쌍피로 쓴 국진은 피로 뺏길 수 있어요.

## 고 · 스톱

- 내 차례가 끝났을 때 점수가 **맞고 7점 · 셋이 3점** 이상이면 **고**(계속) 또는 **스톱**(끝내기)을 골라요.
- 고한 뒤에는 마지막 고 때보다 점수가 올라야 다시 고를 수 있어요 (뺏겨서 깎이면 다시 채워야 함).
- 낼 패가 더 없으면(손패도 뒤집기만도 없으면) 저절로 스톱이에요.
- 고 보너스: 1고 +1점 · 2고 +2점 · 3고부터 **(점수 + 고 횟수) × 2^(고−2)** (3고 ×2, 4고 ×4 …).
- 아무도 못 나고 모두 손패를 다 내면 **나가리**: 다음 판은 ×2 (연달아 나면 ×4, ×8까지).

## 정산 (진 사람마다)

이긴 사람 점수(고 보너스까지) × 아래 배수:

| 배수 | 조건 |
|---|---|
| 흔들기·폭탄 | 이긴 사람이 한 번마다 ×2 |
| 멍박 | 이긴 사람 열끗이 7장 이상 → 모두에게 ×2 |
| 피박 | 이긴 사람이 피로 점수를 냈고(피 10장 이상), 진 사람 피가 1~7장(맞고) / 1~5장(셋이) → ×2. 피 0장은 면제 |
| 광박 | 이긴 사람이 광으로 점수를 냈고, 진 사람 광이 0장 → ×2 |
| 고박 (맞고) | 고를 했던 사람이 지면 ×2 |
| 고박 (셋이) | 고를 했던 사람이 지면 진 사람 몫을 **혼자 다** 냄 (둘 다 고했으면 나중에 고한 사람) |
| 나가리 판 | 앞 판이 나가리였으면 ×2 (연달아 ×4 …) |

- 총통·쓰리뻑은 정해진 점수 × 나가리 배수만 (박은 없음).

## 이 게임에서 쓰지 않는 규칙

독박 · 두 장 폭탄 · 총통을 미루고 계속하기 · 보너스 피로 피 뺏기는 쓰지 않아요. (첫뻑/연뻑 보너스는 기본으로 꺼져 있고, 우리 집 규칙에서 켤 수 있어요.)

## 🛠️ 우리 집 규칙 (바꿀 수 있는 것)

메뉴(혼자 · 한 기기 · AI 구경)의 **🛠️ 우리 집 규칙** 단추, 친구랑 대기실의 **🛠️ 우리 집 규칙** 줄(방장만 바꾸고 친구는 읽기만)에서 바꿔요. 묶음을 누르면 한꺼번에 바뀌고, 그 뒤 항목을 하나씩 더 바꿔도 돼요. 혼자·한 기기의 규칙은 이 기기에 저장돼요. 코드에서는 `cfg.rules` 한 덩어리(`Gostop.normRules` 가 범위 밖 값을 고쳐 줌)이고, 안 주면 모두 기본값이에요.

**묶음**: 기본 · 맞고 표준(보너스 쌍피 3장) · 동네 고스톱(총통은 승리 · 첫뻑 3점 · 연뻑 5점 · 쓰리뻑 10점 · 보너스 쌍피 2장) · 순한 맛(박·고박 없음, 한 판 30점까지) · 화끈한 집(피 두 장씩 뺏고 · 고는 ×2씩 · 피박·광박 ×3 · 첫뻑 5점 · 연뻑 10점).

| 항목 (`키`) | 기본 | 고를 수 있는 값 |
|---|---|---|
| 맞고 고/스톱 기준 (`goMatgo`) | 7점 | 1~30점 |
| 3인 고/스톱 기준 (`go3`) | 3점 (4~5명도 이 기준) | 1~30점 |
| 고 보너스 방식 (`goBonus`) | 기본 | 기본(1고 +1 · 2고 +2 · 3고부터 (점수+고)×2^(고−2)) · 고마다 +1점 · 고마다 ×2 · 없음 |
| 고박 (`gobak`, `gobakX`) | 켬, 맞고 ×2 | 끔 / 맞고 배수 1~5 (3인은 진 사람 몫을 혼자 내기) |
| 피박 (`pibak`, `pibakX`) | 켬 ×2 | 끔 / 1~5배 |
| 광박 (`gwangbak`, `gwangbakX`) | 켬 ×2 | 끔 / 1~5배 |
| 멍박(열끗박) (`meongbak`, `meongbakX`) | 켬 ×2 (열끗 7장↑) | 끔 / 1~5배 |
| 흔들기·폭탄 배수 (`shakeX`) | ×2 (한 번마다) | 1~4 (1이면 배수 없음) |
| 총통 (`chongtong`) | 10점 | 10점 · 승리(고/스톱 기준 점수) · 안 씀(그냥 계속) |
| 쓰리뻑 (`ppeok3`, `ppeok3Pts`) | 바로 승리, 기준 점수 | 안 씀 / 점수 직접 정하기 (0 = 기준 점수) |
| 첫뻑 보너스 (`ppeokFirst`) | 없음 | 1~20점. 판의 **첫 차례**에 난 뻑을 먹으면 싼 사람에게서 받음 (자뻑이면 나머지 모두에게서). 이기든 지든 따로 주고받음 |
| 연뻑 보너스 (`ppeokYeon`) | 없음 | 1~20점. 같은 사람이 **연달아** 두 번 싼 뻑의 두 번째를 먹으면 받음 |
| 국진 (`kook`) | 고르기 | 먹을 때 고르기 · 열끗 고정 · 쌍피 고정 |
| 보너스 쌍피 (`bonus`) | 없음 | 없음 · 2장 · 3장 |
| 피 뺏기 장수 (`stealJjok` `stealTtadak` `stealSweep` `stealBomb` `stealEat` `stealSelf`) | 쪽 1 · 따닥 1 · 싹쓸이 1 · 폭탄 1 · 남의 뻑 1 · 자뻑 2 | 각각 0~3장 (마지막 차례는 여전히 안 받음) |
| 나가리 다음 판 배수 (`nagariX`) | ×2 | 1~4 (1이면 없음) |
| 연속 나가리 한도 (`nagariMax`) | 3번 (8배) | 0~5번 (0이면 안 쌓음) |
| 광 팔기 (`saleOn`) | 켬 | 끄면 쉬는 사람은 패 없이 구경만 |
| 광 한 장 값 (`salePrice`) | 1점 | 0~5점 |
| 살 수 있는 사람 (`saleWho`) | 모두 (선부터 차례로) | 모두 · 선만 · 선 빼고 |
| 최대 점수 상한 (`maxPts`) | 없음 | 5~200점. 한 사람이 한 판에 내는 점수(박·고박 몫까지)가 이 값에서 끊김 |
| 점당 칩 (`chipPer`) | 10칩 | 1~1000칩 (친구랑 정산용, 게임 점수에는 영향 없음) |

- 꺼진 박·배수 1은 정산 내역에도 안 나와요.
- 4~5명 광 팔기에서도 같은 규칙이 쓰여요 (고/스톱 기준은 3인 기준).
- **칩 정산**: 한 판이 끝나면 `점수 변화 × 점당 칩`이 자리마다 계산돼요 (이긴 사람 +받은 점, 진 사람 −낸 점, 광값은 산 사람 → 판 사람, 첫뻑/연뻑은 먹은 사람 ← 싼 사람). 쉬는 사람 자리도 있고 합은 늘 0이에요. 화면은 `window` 의 `chips:report` 이벤트(`{ game:'gostop', kind, round, over:false, deltas:{자리번호:칩}, coins:[자리별 칩 전체], seats:[{name,ctrl,uid}], me }`)로 알려요 (친구랑에서는 방장만). 방장이 대기실에서 🏦 은행 모임을 고르면 시작 칩은 각자 잔액, 판마다 장부에 쓰이고, 칩이 모자라면 다음 판 전에 자동으로 빌려요 (💰 빌리기 단추로 더 빌릴 수도 있어요). 공짜로 채워 주지는 않아요.
