# 고스톱 — 강화학습용 안내 (RL.md)

`core.js`(전역 `Gostop`, Node 에서는 `require('./core.js')`)만 있으면 화면 없이 판을 돌릴 수 있어요. 규칙은 [RULES.md](RULES.md) 한 가지.

## 파일

| 파일 | 하는 일 |
|---|---|
| `core.js` | 규칙 전부. 순수 함수 + JSON 상태, `Math.random`·`Date` 없음 (난수는 상태 안 mulberry32) |
| `ai.js` | 🐣 easy · 🐱 normal · 🐯 hard. `view` 만 받아서 숨은 패를 못 봄 |
| `ai-worker.js` | 브라우저에서 🐯 계산을 Web Worker 로 |
| `test/selftest.js` | 규칙·결정성·숨은 정보·AI 대결 시험 (`node game/gostop/test/selftest.js`, 약 20초) |

## 한 판 돌리기 (Node)

```js
const G = require('./core.js');
let s = G.create({ players: 2, bonus: 0, seed: 1234 });   // players 2|3, bonus 0|2|3
while (s.phase !== 'end') {
  const p = s.turn;                          // 지금 결정할 사람 (늘 s.turn)
  const o = G.obs(s, p);                     // Float32Array(G.OBS_LEN)
  const mask = G.legalMask(s);               // Uint8Array(G.N_ACTIONS), 1 = 할 수 있음
  const a = pickFromPolicy(o, mask);         // 행동 번호
  const { state, events } = G.step(s, a);    // 순수 함수 (s 는 그대로). 빠르게는 G.apply(s, a) (제자리)
  s = state;
}
const r0 = G.reward(s, 0);                   // 이기면 +받은 점, 지면 -낸 점, 나가리 0
s = G.nextRound(s);                          // 다음 판 (이긴 사람이 선, 나가리면 배수 ×2)
```

- 한 판 = 맞고 20차례 안팎(행동은 고르기·고/스톱·국진 때문에 조금 더), 3인 21차례 안팎.
- 보상은 판 끝에만. 점수는 배수 때문에 꼬리가 길어요(이긴 판 중간값 14점, 90% 34점, 드물게 수백 점) → 학습할 때는 `sign(r) * log1p(|r|)` 처럼 눌러 쓰는 걸 권해요.

## 상태 (JSON 그대로 저장 가능)

| 칸 | 뜻 |
|---|---|
| `n` | 2 또는 3 |
| `bonus` | 보너스 피 장수 0·2·3 (id 48 쌍피 · 49 쓰리피 · 50 쌍피) |
| `seed`, `rng` | 이 판 씨앗, mulberry32 상태 (int32) |
| `round`, `carry`, `first` | 몇 판째, 나가리 배수 지수(2^carry), 선 |
| `turn`, `phase` | 결정할 사람, `play` · `pickHand` · `pickFlip` · `kook` · `goStop` · `end` |
| `deck` | 더미 (배열 **끝이 맨 위**) |
| `hands[p]`, `table`, `cap[p]` | 손패(번호 순), 바닥(놓인 순), 먹은 패 |
| `kook` | 국진 쓰임 `''`(아직) · `'Y'` 열끗 · `'P'` 쌍피 |
| `go[p]`, `lastGo[p]`, `goSeq` | 고 횟수, 마지막 고 때 점수, 고한 순서 |
| `shake[p]`, `shook[p]`, `known[p]` | 흔들기+폭탄 횟수, 흔든 달, 흔들어 보인 손패 |
| `pass[p]`, `ppeok[p]`, `owner[m]` | 폭탄 뒤 뒤집기만 남은 수, 뻑 횟수, 바닥 뻑 더미 주인(-1 없음) |
| `cur` | 차례 중간 정보 (낸 패 `c`, 뒤집은 패 `flip`, 고를 후보 `opts`, 가져올 패 `caps` …) |
| `result` | 판 끝 정산 (`kind`, `winner`, `items`, `mults`, `per[]`, `points`) |

패 번호 `id = 월(0~11) × 4 + k`. 종류는 `G.KIND[id]` (0 광 · 1 열끗 · 2 띠 · 3 피), 피 값 `G.PIV`, 띠 종류 `G.RIB` (1 홍단 · 2 청단 · 3 초단 · 4 비띠), 고도리 새 `G.BIRD`. 국진 = 32, 비광 = 44.

## 행동표 (`G.N_ACTIONS` = 118)

| 번호 | 뜻 | 언제 |
|---|---|---|
| 0~50 | `A_PLAY + id`: 손패 `id` 내기 (보너스 피 48~50 포함) | play |
| 51~98 | `A_SHAKE + id`: 흔들고 `id` 내기 (손에 같은 달 3장, 바닥엔 0장) | play |
| 99~110 | `A_BOMB + 월`: 폭탄 (손에 3장 + 바닥에 1장) | play |
| 111 | `A_PASS`: 뒤집기만 (폭탄 뒤) | play |
| 112, 113 | `A_PICK + 0/1`: 바닥 두 장 중 고르기 (`cur.opts` 번호 작은 쪽이 0) | pickHand · pickFlip |
| 114, 115 | `A_GO`, `A_STOP` | goStop |
| 116, 117 | `A_KOOK_Y` 열끗으로, `A_KOOK_P` 쌍피로 | kook |

할 수 없는 행동을 넣으면 `apply` 가 오류를 던져요 → 늘 `legalMask` 로 가려서 고르세요. `G.actionLabel(a)` 은 사람이 읽는 이름.

## 관찰 `obs(s, p)` (`G.OBS_LEN` = 558, 0~1 값)

`obs` 는 안에서 `view(s, p)` 를 거쳐 만들어서 **p 가 모르는 것(남의 손패·더미 순서·씨앗)은 들어갈 수 없어요** (selftest 가 숨은 패만 다시 섞은 판과 관찰이 똑같은지 매번 확인).

| 위치 | 길이 | 내용 |
|---|---|---|
| 0 ~ 407 | 51 × 8 | 패마다 8칸 one-hot: 0 내 손 · 1 바닥 · 2 내가 먹음 · 3 상대1 먹음 · 4 상대2 먹음 · 5 상대1 손(흔들어 보인 패) · 6 상대2 손(보인 패) · 7 모름(더미 또는 남의 숨은 손패). 이 판에 없는 보너스 번호는 0 |
| 408 ~ 458 | 51 | 지금 고를 후보 (`cur.opts`) |
| 459 ~ 509 | 51 | 이번 차례에 낸 패·뒤집은 패 |
| 510 ~ 515 | 6 | phase one-hot (play, pickHand, pickFlip, kook, goStop, end) |
| 516 ~ 517 | 2 | 3인인가, 더미 장수/30 |
| 518 ~ 520 | 3 | 손패 수/10 (나, 상대1, 상대2) |
| 521 ~ 523 | 3 | 지금 점수/10 |
| 524 ~ 538 | 15 | 고/3 · 흔들기/2 · 뒤집기만/2 · 뻑/3 · 마지막 고 점수/10 (각 3자리) |
| 539 ~ 542 | 4 | 국진 열끗 · 국진 쌍피 · 나가리 배수 지수/3 · 고 기준점/7 |
| 543 ~ 545 | 3 | 차례 one-hot (나, 상대1, 상대2) |
| 546 ~ 557 | 12 | 자리마다 피/20 · 광/5 · 열끗/9 · 띠/10 |

상대1 = `(p+1) % n`, 상대2 = `(p+2) % n` (맞고는 상대2 자리가 다 0).

## 결정성

- 같은 `seed` + 같은 행동 순서 → 같은 상태 지문 `G.hash(s)` (selftest 확인). `step` 은 넣은 상태를 안 바꿈.
- 섞기 · 다시 섞기 · 다음 판 씨앗 모두 상태 안 `rng`(mulberry32)에서. `nextRound(s)` 도 결정적.
- AI 도 `makeRng(seed)` 로 받은 난수만 써요. 🐯 은 화면에서는 시간 예산(`ms`), 시험에서는 횟수(`samples`)로 돌려야 결과가 늘 같아요.

## 디버그 / 숨은 정보

- `G.view(s, p)`: p 에게 보이는 상태 (남의 손패는 흔든 패만 앞에, 나머지 `-1`; 더미는 `-1` 로 장수만; `seed`·`rng` 0). 온라인 대전에서 보낼 것도 이것.
- `G.sampleWorld(view, rand)`: 보이는 정보와 맞게 숨은 패를 고르게 섞은 온전한 상태 하나 (결정화 몬테카를로용).
- `G.debugFull(s)`: 다 보이는 상태 그대로 (디버그 전용).
- 시험용 판 만들기: `G.setup({ players, hands, table, deck (뒤집을 순서), cap, ... })`.

## 지금 AI (기준선)

| 등급 | 방식 |
|---|---|
| 🐣 easy | 바로 먹을 수 있는 패 위주 + 25% 아무거나, 고는 가끔 |
| 🐱 normal | 뒤집힐 수 있는 패(보이지 않는 패, 같은 값끼리 묶음)를 하나하나 가정한 한 수 앞 기댓값. 평가 = 내 값어치(점수 + 약에 다가간 정도, 이미 막힌 약은 0) − 상대 값어치 + 바닥에 남긴 패를 다음 사람이 가져갈 위험·내가 가져올 기회. 고/스톱은 규칙 |
| 🐯 hard | 패 내기는 🐱 과 같고, **고/스톱을 결정화 몬테카를로**로: 숨은 패를 보이는 정보에 맞게 수십~수백 번 섞어 '고' 한 뒤 빠른 정책으로 끝까지 둬 본 평균과 지금 스톱한 점수를 비교 (Web Worker, 320ms) |

벤치 (같은 판을 자리 바꿔 두 번, 10스레드, `normal vs hard` 500쌍): 🐯 이 판마다 **+16.6 ± 3.0점** (맞고), 3인 +2.5 ± 0.7점. selftest 의 다른 씨앗 300쌍(고/스톱 40번 끝까지 두기)에서는 +7.9 ± 1.9점 · 3인 +2.2 ± 0.9점 — 판 운이 커서 씨앗 묶음마다 차이가 있지만 늘 🐯 > 🐱. 🐱 은 🐣 보다 맞고 +11.0 ± 1.2점.
패 내기까지 몬테카를로로 고치는 것(`opts.beta > 0`)도 해 봤는데, 빠른 정책이 치우쳐서 오히려 약해졌어요(β=0.2: +11.0, β=0.5: +8.5 vs β=0: +16.7) → 기본은 끔. 강화학습 정책이 이 자리를 채우면 좋아요.

## 학습한 정책을 끼우는 법

1. 정책 = `(obs: Float32Array, mask: Uint8Array) → 행동 번호` 하나면 돼요. 마스크 밖 행동은 확률 0.
2. `ai.js` 의 `TIERS` 에 새 등급(예: `rl`)을 넣고 `choose(view, 'rl')` 에서 `G.obs(view, view.me)` · `G.legalMask(view)` 로 부르면, 화면·AI 구경·시험이 전부 그대로 써요 (`view` 를 받으므로 숨은 정보는 못 봄).
3. 브라우저에서는 `ai-worker.js` 안에서 가중치를 불러 계산 (예: onnxruntime-web 를 jsDelivr 고정 버전으로, `.onnx` 는 이 폴더에). 화면 쪽 `aiChoose()` 가 일꾼 결과를 기다려요.
4. 자리마다 누가 두는지는 `main.js` 의 `seats[p].ctrl` ('me' | 'ai') — 나중에 친구(원격) 자리도 같은 행동 번호를 주고받으면 돼요.
5. 셀프플레이 상대는 `easy`/`normal`/`hard` 를 섞으면 좋아요. 🐯 은 끝까지 두기가 비싸니 `samples` 를 작게.
