규칙 요약
  • 매 라운드 기본 골드 + 이자(10골드당 1) + 연승·연패 보너스.
  • 상점 5칸, 새로고침 2골드, 경험치 4골드 = 4XP. 레벨이 오르면 보드 칸이 늘고 비싼 유닛이 잘 나옵니다.
  • 같은 유닛 3개 = 2성, 2성 3개 = 3성. 유닛은 모두가 같은 공유 풀에서 나옵니다.
  • 보드 = 힘 센 순서로 레벨 수만큼 자동 배치. 나머지는 벤치(눌러서 팔기).
  • 회전목마 라운드엔 유닛+아이템, PvE 라운드엔 아이템(이기면 골드도).
  • 랭크 규칙의 숫자(확률·풀·XP·이자·연승·판매가)는 TFT Set 18 공개 수치, 챔피언·특성·그림은 Set 18 실제 데이터(CommunityDragon).
  • 특성은 보드에 표시만 합니다. 전투 힘에는 아직 안 들어갑니다.
