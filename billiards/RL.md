# 당구 — 강화학습용 안내 (RL.md)

`core.js`(전역 `Billiards`, Node 에서는 `require('./core.js')`)만 있으면 화면 없이 판을 돌릴 수 있어요. 물리·규칙 모두 순수 함수 + JSON 상태, `Math.random`·`Date` 없음 (랙 섞기 난수는 상태 안 mulberry32).

## 파일

| 파일 | 하는 일 |
|---|---|
| `core.js` | 물리(미끄러짐·굴림·회전·쿠션·공끼리·포켓) + 규칙(4구·3쿠션·8볼) + 관측 `obs` |
| `ai.js` | 🐣 easy · 🐱 normal · 🐯 hard — 시뮬레이터로 후보 샷을 쳐 보고 고름(+ 손떨림). `coach` = AI 선생님 |
| `draw.js` · `main.js` | 화면 (학습에는 필요 없음) |
| `test/selftest.js` | 물리 성질·규칙·결정성·속도·AI 시험 (`node billiards/test/selftest.js`, 10초 안팎) |

## 한 판 돌리기 (Node)

```js
const B = require('./core.js');
let s = B.create({ mode: '3c', players: 2, target: 10, seed: 1234 });   // mode '4gu' | '3c' | '8ball'
while (s.phase === 'play') {
  const p = s.turn;
  const o = B.obs(s, p);                       // Float32Array(B.OBS_LEN) — 값 0~1
  const a = policy(o);                         // { angle, power, spinX, spinY, place? }
  const { state, sim, result } = B.applyShot(s, a);   // 순수 함수 (s 는 그대로)
  const r = B.reward(s, state, p);
  s = state;
}
```

- 한 샷 계산은 PC 에서 평균 약 1ms(최대 힘 8볼 브레이크도 5ms 안팎). 프레임을 안 남기려면 `B.simulate(s, a, { record: false })`.
- 학습 속도를 더 내려면 `applyShot(s, a, { maxTime: 12 })` 처럼 한 샷 시간을 자를 수 있어요 (기본 40초).

## 행동 (4개 + 프리볼 자리)

| 칸 | 범위 | 뜻 |
|---|---|---|
| `angle` | 0 ~ 2π (라디안) | 당구대 좌표에서 칠 방향. x = 긴 쪽(헤드 0 → 풋 L), y = 짧은 쪽 |
| `power` | 0.01 ~ 1 | 큐 속도 = `vmax × power^1.5` (캐롬 vmax 7.2 m/s, 포켓 9.5 m/s) |
| `spinX` | −1 ~ 1 | 당점 좌우 (오른쪽 +). 반지름의 0.55배까지 |
| `spinY` | −1 ~ 1 | 당점 위아래 (위 = 밀어치기 +, 아래 = 끌어치기 −). `hypot(spinX, spinY) ≤ 1` 로 잘림 |
| `place` | `[x, y]` (m) | `s.ballInHand` 일 때만. 놓을 수 없는 자리면 `fixPlace` 가 가까운 빈자리로 옮김 (브레이크는 x ≤ L/4) |

연속 행동이라 SAC·PPO(가우시안)·CEM 이 잘 맞아요. 이산화하려면 각도 0.25°(1440칸) × 힘 8칸 × 당점 5칸 정도에서 시작하길 권해요 (3쿠션은 각도 0.1° 차이로 성패가 갈림).

## 관측 `obs(s, p)` — 길이 `B.OBS_LEN` (= 61)

| 칸 | 뜻 |
|---|---|
| 0 ~ 47 | 공 16칸 × [있음 0/1, x/L, y/W]. **0번 칸은 늘 내 수구** (캐롬에서 노란 공 차례면 흰·노란 칸을 바꿔 줌). 캐롬은 3~4칸만 쓰고 나머지 0 |
| 48 ~ 50 | 종목 원핫 (4구, 3쿠션, 8볼) |
| 51, 52 | 내 점수 / 필요 점수, 상대 최고 점수 / 필요 점수 |
| 53, 54 | 프리볼, 키친(브레이크 자리 제한) |
| 55 ~ 57 | 8볼 내 공 종류: 단색, 줄무늬, 아직 오픈 |
| 58 | 내 공 남은 수 / 7 |
| 59 | 브레이크 샷인가 |
| 60 | 지금 연속 득점 / 10 |

3쿠션은 위치만으로 충분하지만, 학습이 잘 안 되면 수구→각 공의 거리·각도, 쿠션 다이아몬드 좌표 같은 특징을 덧붙여 보세요.

## 보상 `reward(prev, next, p)`

- 판이 끝나면 이긴 사람(8볼은 이긴 팀) +1, 진 쪽 −1
- 캐롬: 그 밖에는 `(점수 변화) / 필요 점수` (4구 감점은 음수)
- 8볼: 판 끝 말고는 0 → 공을 넣을 때 작은 보상(예: `result.score * 0.05`)을 더하면 빨라져요
- 3쿠션 성공률이 처음엔 거의 0이라, `ai.js` 의 `scoreCarom` 처럼 '두 번째 공에 얼마나 가까이 갔나'를 모양 보상으로 쓰면 좋아요

## 상태 (JSON 그대로 저장 가능)

| 칸 | 뜻 |
|---|---|
| `mode`, `table` | 종목, 당구대(`carom` 대대 2.844×1.422 · `carom4` 중대 2.54×1.27 · `pool` 9피트 2.54×1.27) |
| `n`, `turn` | 사람 수 1~4, 지금 칠 사람 |
| `balls[i]` | `{x, y, on}` — 캐롬 0 흰 · 1 노란 · 2 빨강 (· 3 빨강2), 포켓 0 수구 · 1~15 |
| `scores`, `innings`, `high`, `run` | 점수, 이닝 수, 하이런, 지금 연속 |
| `target`, `finish3c` | 목표 (4구는 다마 수 → `needPoints` = 다마/10), 4구 마무리 쓰리쿠션 |
| `groups[team]` | 8볼 팀(0: 짝수 자리, 1: 홀수 자리) 공 종류 `'solid' | 'stripe' | null` |
| `ballInHand`, `kitchen`, `breakShot` | 프리볼, 브레이크 자리 제한, 첫 샷 |
| `phase`, `winner`, `winTeam` | `'play' | 'end'` |
| `seed`, `rng` | 씨앗, mulberry32 상태 |

캐롬에서 짝수 자리는 흰 공, 홀수 자리는 노란 공을 쳐요 (3~4명이면 같은 공을 번갈아).

## 물리 요약

- 고정 간격 1/60초, 그 안을 가장 빠른 공이 반지름의 0.3배보다 덜 움직이게 잘게 나눔 → 최대 힘에서도 뚫고 지나가지 않음
- 미끄러짐(μs 0.2) → 굴림(μr ≈ 0.013 + 약한 속도 비례 감쇠), 옆 회전은 천천히 줄어듦
- 공끼리: 반발 0.94~0.96 + 닿는 면 마찰(던짐)로 옆 회전이 조금 옮겨감. 회전은 충돌 뒤에도 남아 밀어치기·끌어치기가 저절로 나옴
- 쿠션: 반발 0.82(캐롬)/0.78(포켓) + 닿는 점 미끄러짐 마찰(옆 회전이 각을 길게/짧게) + 굴림 회전 일부 감쇠
- 포켓: 쿠션 줄을 넘거나(틈으로만 가능) 모서리 깊숙이 들어가면 들어감. 포켓 끝 턱은 점 충돌
- 결정성: 같은 상태 + 같은 행동 = 같은 궤적 (같은 JS 엔진 안에서. 친구랑은 방장이 계산한 궤적을 보내므로 기기마다 달라도 괜찮음)
